# Community conduct

Welcome contributors with different backgrounds and experience. Communicate respectfully, focus criticism on the work and give constructive, evidence-based feedback. Harassment, discrimination, threats, sexualized conduct, doxxing and disclosure of others' private information are unacceptable.

This applies to project issues, pull requests, discussions and other official project spaces. Maintainers may edit or remove harmful material, restrict participation or ban repeat offenders, proportionately and with an explanation where practical. Maintainers follow the same expectations.

For a sensitive conduct report, use an available private GitHub reporting channel or request a private channel without posting personal details publicly. The maintainer will handle reports discreetly and avoid unnecessary disclosure. Ordinary technical disagreement is welcome when expressed respectfully.
